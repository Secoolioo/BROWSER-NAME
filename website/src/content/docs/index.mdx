A desktop browser for Windows, macOS and Linux, built on Chromium through Electron. Start-up
time and memory stay within budgets that every change is measured against. There is no
telemetry, no ads, no sponsored tiles, no news feed and no account.

## In place

- Packages for Windows (NSIS installer, MSI), macOS (disk image) and Linux (AppImage, deb, rpm),
  for x64 and arm64. Every format is installed and started in CI on every change.
- Signed updates with delta downloads. After two failed starts, the previous version comes back
  on its own. deb and rpm packages update through APT and DNF repositories.
- Policies from the Windows registry, macOS configuration profiles and JSON files on Linux, read
  before the first window opens.
- Budgets for start-up time, memory, CPU and bundle size, measured against a bare Electron app on
  all three systems for every change. See [performance](docs/architecture/performance/).
- Security fixes from Electron ship in a patch release within 72 hours, critical ones within
  24 hours.

## Planned for 0.1.0

- Workspaces, tab bars on any side of the window, tab groups and layout presets.
- Themes with an editor, three density levels, custom shortcuts and a searchable settings page.
- History, bookmarks, downloads, session restore and private windows.
